Machine Learning in One Line

Libra is a Python tool for fully automated machine learning that enables you to create complex ML models with just one line of code. No more complex configurations, hyperparameter tuning, or model selection headaches.

Quick Start 
from libra import client

# Create and train a model in one line
newClient = client('data.csv')
newClient.neural_network_query('target_column')

Interactive Code Examples

Explore different machine learning tasks with Libra's one-line approach

Binary Classification

Predict binary outcomes with automated model selection and hyperparameter tuning.

classification_example.py 
from libra import client

# Load your dataset and create a classification model
newClient = client('customer_data.csv')
newClient.classification_query_neural_network('will_purchase')

# That's it! Libra handles:
# - Data preprocessing
# - Feature engineering
# - Model selection
# - Hyperparameter optimization
# - Cross-validation

Regression Analysis

Predict continuous values with automated feature selection and model optimization.

regression_example.py

Deep Neural Networks

Build sophisticated neural networks without writing complex architectures.

neural_network_example.py 
from libra import client

# Create a deep neural network for image classification
newClient = client('image_dataset/')
newClient.neural_network_query('image_labels')

# Libra automatically:
# - Designs optimal network architecture
# - Selects appropriate activation functions
# - Implements regularization techniques
# - Monitors training progress
