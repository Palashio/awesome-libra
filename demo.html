🌱 For Beginners

Beginner Friendly

New to machine learning? No problem! Libra makes it incredibly simple to get started.

Goal: Create a machine learning model to predict house prices with just one line of code!

Complete Example:

from libra import client # Load your data and create a model in one line! client('housing_data.csv').regression('price')
✅ Model trained successfully! 📊 Accuracy: 94.2% 💾 Model saved as 'regression_model.pkl'

In that single line, Libra:

  • ✨ Loaded and analyzed your CSV data
  • 🧹 Cleaned and preprocessed the data automatically
  • 🤖 Selected the best machine learning algorithm
  • ⚙️ Tuned the model parameters for optimal performance
  • 📈 Trained the model and evaluated its accuracy
  • 💾 Saved the trained model for future use

No coding experience required! Libra handles all the complex machine learning steps behind the scenes.

⚡ For Experienced Developers

Intermediate

Want more control? Libra allows you to customize parameters while keeping things simple.

from libra import client # Email spam detection with custom settings newClient = client('email_data.csv') newClient.classification( target='is_spam', test_size=0.2, drop=['email_id', 'timestamp'], preprocess=True, callback=True )

Here you can specify:

  • test_size: How much data to use for testing
  • drop: Columns to exclude from training
  • preprocess: Enable advanced preprocessing
  • callback: Get detailed training progress
from libra import client # Image classification with neural networks newClient = client('image_dataset/') newClient.neural_network_query( target='category', epochs=50, learning_rate=0.001, batch_size=32, test_size=0.15 )
🧠 Neural network training started... 📊 Epoch 1/50 - Loss: 0.8234 - Accuracy: 0.7123 📊 Epoch 25/50 - Loss: 0.2156 - Accuracy: 0.9234 📊 Epoch 50/50 - Loss: 0.1023 - Accuracy: 0.9567 ✅ Training completed! Final accuracy: 95.67%

🎯 For ML Engineers

Advanced

Need fine-grained control? Access all the advanced parameters and customization options.

from libra import client # Advanced regression with full customization newClient = client('financial_data.csv') newClient.regression( target='stock_price', algorithm='random_forest', test_size=0.25, cross_validation=5, feature_selection=True, scaling='standard', outlier_removal=True, polynomial_features=2, regularization='l2', hyperparameter_tuning={ 'n_estimators': [100, 200, 300], 'max_depth': [10, 20, 30], 'min_samples_split': [2, 5, 10] }, save_model='custom_financial_model.pkl', generate_plots=True, verbose=True )

Advanced parameters include:

  • algorithm: Specify exact ML algorithm
  • cross_validation: K-fold cross-validation
  • feature_selection: Automatic feature engineering
  • hyperparameter_tuning: Custom parameter grid search
  • regularization: L1/L2 regularization options
from libra import client # Define custom neural network layers newClient = client('complex_dataset.csv') newClient.neural_network_query( target='outcome', layers=[ {'type': 'dense', 'neurons': 128, 'activation': 'relu'}, {'type': 'dropout', 'rate': 0.3}, {'type': 'dense', 'neurons': 64, 'activation': 'relu'}, {'type': 'batch_norm'}, {'type': 'dense', 'neurons': 32, 'activation': 'relu'}, {'type': 'output', 'activation': 'softmax'} ], optimizer='adam', loss_function='categorical_crossentropy', metrics=['accuracy', 'precision', 'recall'], early_stopping=True, learning_rate_schedule='exponential_decay', data_augmentation=True )
